# Камень, дерево, вода

Интерактивный путеводитель по Республике Карелия и туристический маршрут из 12 остановок от Ладоги до Белого моря. Учебный проект по заданию «Создание интерактивного путеводителя по региону».

Сайт: https://dmitryzap.github.io/kamen-derevo-voda/

## Что внутри

- Девять глав-страниц: регион, население, экономика, культура, люди, маршрут, летопись, викторина, источники.
- Карта-схема с 12 остановками, фильтром по материалу и проходом маршрута.
- Графики, сравнение площадей, «сто жителей Карелии», цепочки «что из чего делают».
- 75 фотографий с Викисклада, авторы и лицензии перечислены в [CREDITS.md](CREDITS.md).

## Как устроено

Сайт статический: `index.html` и папка `photos/`. Серверной части и внешних библиотек нет, шрифты вшиты в страницу.

- `photos/` — снимки шириной до 1600 px, `photos/s/` — уменьшенные копии для миниатюр.
- `src/` — исходники: `base.html` (содержание и данные), стили, скрипты и `build.py`, который собирает из них `index.html`.

Пересобрать страницу:

```
cd src
npm install
python3 build.py
```

## Что стоит знать

- Статистика дана с годом, к которому относится (источники в последней главе сайта). Исторические даты, размеры объектов и слова на карельском и вепсском приведены по энциклопедическим сведениям и перед защитой требуют сверки.
- Карта нарисована как схема: очертания упрощены, точки стоят по географическим координатам.
- Фотографии принадлежат их авторам и распространяются по лицензиям, указанным в CREDITS.md.
